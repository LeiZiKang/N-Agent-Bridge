N Agent Bridge 配置故障诊断报告

日期：2026-08-15 CST · 产品：0.15.0 (57) · 设备：NuPhy Air75 V3 ANSI · USB：19F5:1028

结论摘要

“点击后没有反应”的产品根因已经通过独立 Bundle ID 调试版定位。

  • 配置流程实际已进入：B2 成功读取完整 1568 bytes，随后在写入前的布局白名单校验中停止。
  • 精确根因：第 1 层旋钮按下位置 p60 为 0x00AE（Play/Pause），而 0.15.0 只接受该位置的已验证出厂/Bridge 值。程序把这个正常的 NuPhyIO 自定义误归类为“加密会话数据”，UI 因而没有给出可执行原因。
  • 安全处置：本次没有发送 B3，没有改变键位表，也没有保存不合格原始备份。源码现会明确要求先在 NuPhyIO 把第 1 层旋钮按下恢复为 Mute，再退出 NuPhyIO 后配置；白名单没有放宽。
  • 状态灯写入失败：已经由真机 Probe 稳定复现。D8 返回 ACK，但写入 F1 新颜色 #123456 后，D2 实际回读为 #000000。控制器按安全规则尝试恢复并返回失败。

D8 问题会造成 Agent 状态灯失败，但按当前代码顺序，它不应阻止首次 B2/B3 键位配置：键位写入和完整回读发生在状态灯同步之前。
